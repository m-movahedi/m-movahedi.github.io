This scratchpad collects the **LLM introduction series**, an eight-part walkthrough from transformer basics to responsible deployment.

**Target audience:** Graduate students, researchers, and technically curious professionals who want a concrete understanding of how large language models work, how to use them well, and where they fail. A basic statistics background is helpful but not required.

**Domain thread:** Many examples use evacuation and transportation planning as a running case, but the concepts apply broadly.

### Series Overview

1. **[LLM 101: Transformers, Training, and Inference](llm-101/)** — Tokens, embeddings, self-attention, the training loop, inference, decoding strategies, and model parameters.
2. **[LLM 102: Prompting, Context, RAG, and Hallucinations](llm-102/)** — Prompt design, in-context learning vs fine-tuning, context windows, retrieval-augmented generation, tool use, and hallucination.
3. **[LLM 103: Retrieval-Augmented Generation in Practice](llm-103/)** — Embeddings, chunking, sparse/dense/hybrid search, reranking, prompt assembly, citations, and RAG evaluation.
4. **[LLM 104: Agents, Tools, Memory, and Guardrails](llm-104/)** — The agent loop, tool calling, planning, memory types, multi-agent systems, guardrails, and when not to build an agent.
5. **[LLM 105: Evaluation, Benchmarks, and Measuring Usefulness](llm-105/)** — Use-case evaluation, benchmarks, local eval sets, human review, LLM-as-a-judge, RAG and agent evaluation, regression testing.
6. **[LLM 106: Fine-Tuning, Adaptation, and When to Train](llm-106/)** — The adaptation spectrum, SFT, LoRA/QLoRA, preference tuning, distillation, data quality, and when fine-tuning is the wrong move.
7. **[LLM 107: Deployment, Cost, Latency, and Monitoring](llm-107/)** — Model choice (open vs closed), latency budgets, cost-per-task, KV cache, quantization, caching, monitoring, privacy, and rollouts.
8. **[LLM 108: Safety, Privacy, Bias, and Responsible Use](llm-108/)** — Truthfulness, bias, privacy, misuse, prompt injection, transparency, human oversight, and environmental cost.

Each post includes paper citations for deeper reading, practical checklists, and exercises for self-check.
